# Simple To-Do List Application

A basic command-line To-Do list manager written in Python. Perfect for beginners to practice lists, loops, and user input.

## Features

- Add new tasks
- View all tasks with status (Pending or Completed)
- Mark tasks as completed
- Remove tasks
- Simple menu-driven interface

## Requirements

- Python 3.x (no external libraries needed)

## How to Run

1. Save the code below as `todo.py`.
2. Open a terminal or command prompt.
3. Run: `python todo.py`
